ESXiminator

ELECTRIBE SX REMOTE CONTROL

Your ESX-1's front panel died.
Its brain didn't.

ESXiminator is a free Windows VST3 + standalone app by Aday that becomes the front panel of a Korg Electribe ESX-1 — every part, every knob, every effect, over plain USB-MIDI. Optional beer license. Not affiliated with Korg.

Download MSI installer Portable zip (x64) Getting started

MSI INSTALLER

Two folder pages: (1) Hub/standalone under Program Files, (2) Which VST3 folder should the plugin land in? — default C:\Program Files\Common Files\VST3\ESXiminator.vst3. Clean uninstall from Apps & Features.

HUB APP

Status always shows the full VST path. Install VST3 confirms that location (same Common Files default unless you change it). Updates refresh that same folder — one metal-panel window, no command line.

EVERY PARAMETER

All 15 parts — Drum 1–7B, Stretch, Slice, Audio In, Keys 1/2. Sample & slice select, filter, EG, modulation, FX sends, mutes, accent, swing — addressed per-part via NRPN and panel CCs, exactly per Korg's spec.

MODULATORS

MOD tab: LFOs and friends that drive any parameter, with safe min/max ranges on knobs so MIDI-learned moves stay inside the limits you set.

STEP SEQUENCER

16×13 grid that follows your DAW transport or its own internal clock, with MIDI clock/start/stop generation so the hardware stays tempo-locked.

FULL DAW AUTOMATION

Every control is a VST parameter. Draw automation on anything — it streams to the hardware live. Unlimited motion sequences, courtesy of your DAW.

MIDI LEARN

Right-click any knob, twist your controller, done. Plus a direct MIDI input so a keyboard can play the Keys parts chromatically.

NO DAW REQUIRED

Standalone .exe talks straight to your USB-MIDI interface. The VST3 opens its own MIDI port too — Bitwig's plugin-MIDI filtering can't stop it.

ESX-1 setup: MIDI Filter P/C/E/N = o · Clock AUTO · CC assign factory defaults · channels 1 / 2 / 10
